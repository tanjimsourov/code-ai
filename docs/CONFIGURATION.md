# Configuration

Key environment variables are in `.env.example`.

## Core

- `DJANGO_SETTINGS_MODULE`
- `SECRET_KEY`
- `DEBUG`
- `ALLOWED_HOSTS`
- `CSRF_TRUSTED_ORIGINS`
- `TIME_ZONE`

## Database/Cache

- `DATABASE_URL`
- `REDIS_URL`
- `CELERY_BROKER_URL`
- `CELERY_RESULT_BACKEND`

## Storage

- `STATIC_ROOT`
- `MEDIA_ROOT`
- `CODE_EDITOR_TASK_STORAGE_ROOT`
- `CODE_EDITOR_REPOSITORY_STORAGE_ROOT`
- `CODE_EDITOR_ARTIFACT_STORAGE_ROOT`

## Provider Settings

- `CODE_EDITOR_OLLAMA_*`
- `CODE_EDITOR_OPENAI_COMPATIBLE_*`
- `CODE_EDITOR_VLLM_*`
- `CODE_EDITOR_LLAMA_CPP_*`

## Task/Command Limits

- `CODE_EDITOR_COMMAND_TIMEOUT_SECONDS`
- `CODE_EDITOR_COMMAND_MAX_OUTPUT_BYTES`

## Security/Observability

- `CODE_EDITOR_PUBLIC_MODEL_LISTING`
- `CODE_EDITOR_PUBLIC_METRICS`
- `CODE_EDITOR_METRICS_TOKEN`
- `CODE_EDITOR_THROTTLE_RATE_USER`
- `CODE_EDITOR_THROTTLE_RATE_ANON`

## Upstream Governance

- `CODE_EDITOR_UPSTREAM_SOURCES`
- `CODE_EDITOR_UPSTREAM_STATE_FILE`
